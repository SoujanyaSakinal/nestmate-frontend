# 🏠 NestMate — PG & Hostel Finder

A community-driven platform for students and workers to find PGs and hostels without brokers or agents.

## 🚀 Features
- 🔐 JWT Authentication (Register/Login/Role-based access)
- 🔍 Browse & filter PG listings by city, area, rent, room type
- 📸 Upload up to 3 real photos per listing (Cloudinary)
- ❤️ Save favourite listings
- ⭐ Reviews & ratings system
- ✨ AI-powered description generator (Groq + Llama 3.3)
- 👮 Admin dashboard with live platform stats
- 📱 Mobile responsive UI

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, React Router
- **Backend:** Spring Boot, MySQL, JWT
- **Storage:** Cloudinary
- **AI:** Groq API (Llama 3.3)

## ⚙️ Setup
1. Clone the repo
2. Run `npm install`
3. Run `npm start`
4. Make sure backend is running on port 8080
